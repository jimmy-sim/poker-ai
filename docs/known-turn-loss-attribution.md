# Prospective saved-policy attribution of known turn/river losses

**Issue #4; November 24, 2026 (PST).** This protocol is being published before any new full-row candidate/control trace or ranking. [PR #112](known-turn-regret-recency-result.md) tested one fixed signed-regret discount on two **known, outcome-inspected** turn-start games and failed its frozen wet strength gates. At equal 10,117,956 charged visits, the wet candidate's final linear-average exploitability rose from 1.072987 to 1.707997 chips. Its turn best-response gain rose by 0.411577 chips and river gain by 0.223433. The two previously ranked turn rows rose by only 0.016565 chips together: about 96% of the turn increase lies outside those two rows. This arithmetic from the published fixed report motivates a full-row comparison; it does not establish a cause or a new training outcome. The dry game improved at equal work, so it is a fixed contrast, not an unseen validation case.

## Question and fixed inputs

Where did the discount move exact acting-turn/river best-response weakness relative to the unchanged learner? Is the wet **positive worsening mass** concentrated in a few rows, and how much lies in the 20 already inspected wet rows? The result may guide one later prospective strength hypothesis. It cannot show that a local action swap, more work, another representation or a new learning rule improves play.

Use exactly four published **final linear-average** policies: immutable PR #110 wet and PR #108 dry `signed_full_exact_turn_river` controls, and the one PR #112 `signed_full_exact_turn_regret_recency` candidate on each same game. All used PCG64(0), the same 36-chip initial pot, and exact charged work within game (wet 10,117,956; dry 10,012,410). The [machine contract](../configs/known-turn-loss-attribution.json) pins both spot files, boards, saved own/native/report/final-check manifest hashes, the seed, paths, work, rankings, tolerances, forecast and caps. Preserve the old controls and all four policy snapshots byte for byte. There is **no training, ablation, parameter selection, new reference audit or default change**. The two cases have been repeatedly inspected and are not held-out or independent population samples.

## Frozen readouts and decision rule

Replay each of the four saved policies once. For each acting seat, compute an exact best reply against the other seat's fixed saved policy. Divide unilateral exact-row gain by two, so all row contributions sum to restricted-game NashConv/2 in acting-seat chips. Require exact acting-key identity for both arms, matching row indices, legal actions and board/range game bytes. Require policy hashes, saved actual work, zero recall violations, own score, and the previously published comparison-only OpenSpiel 2.0.2 scalar checks to agree within **1e−9 chips**; nonnegative row gain permits only **1e−12 chips** numerical slack. Reconcile per-street sums and the all-row candidate-minus-control sum to the published PR #112 report within **1e−9 chips**. A mismatch is a correctness stop with retained evidence, not a poker result.

For each game and each of turn and river, calculate every exact row's signed `candidate contribution − control contribution`. The net sum is the already published whole-policy score difference; **positive worsening mass** is the sum of positive row differences, and **negative offset** is the absolute sum of negative differences. Rank all rows by signed difference descending, breaking ties by exact information index ascending; retain the top ten even if some differences are zero or negative. Independently rank candidate absolute contribution the same way and retain its top ten. The fixed previously inspected rows from the machine contract are always shown, including zero-reach rows. Publish the complete full-row vectors, not just these rankings.

Classify a street's **worsening location** as `concentrated` if its top ten positive differences sum to at least **50%** of its positive worsening mass, otherwise `distributed`; if the positive mass is zero, say `none`. Separately call previously inspected rows `dominant` if their positive differences sum to at least **50%** of that street's positive worsening mass, otherwise `nondominant`; `none` if no positive mass. These are descriptive, preregistered thresholds, **not acceptance of poker strength**. Report exact shares, positive/negative/net chips, row counts, each seat, and both games regardless of sign. Show cards, board, pot, legal concrete actions, both saved probabilities, chance-times-opponent counterfactual reaches, full saved-prefix reaches, optimized-continuation alternative-action values and each arm's additive contribution for the fixed top and previously inspected rows. Report saved whole/post-initial-river coverage, memory and path runtime, plus this diagnostic's runtime and peak RSS. Do not substitute a favorable row after ranking.

The two arms have different saved opponent policies, reaches and best-reply continuations. Their per-row difference is an **additive decomposition of exploitability difference**, not a causal value of changing that one action, a common-opponent intervention, or universal poker advice. The game starts on the turn, so this cannot test earlier-street grouping. Exact acting keys remove the specified turn/river collision mechanism in these finite games, but do not prove absence of every implementation defect. No confidence interval is possible from one deterministic seed per related known game.
