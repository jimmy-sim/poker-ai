## Question and fixed scope

A strategy average can look stable while its latest probabilities remain
vulnerable. Does frozen-pass batching change the current policies or mainly their
averages? This is a saved-data diagnosis: never retrain, tune or change policies.
Use all216 current checkpoints from all72 paths and all three work labels. Score
exact/within/extra/river vulnerability and EV with the unchanged own scorer.

For final policies, evaluate all72 currents and144 averages against the same four
original full controls for each spot/encoding: signed/clipped regrets crossed
with uniform/linear averaging, at the original final10m work. These controls
predate new batch outcomes.216 candidates x4 controls x2 responding seats yields
1728 fixed targets. Cache verified own within-partition replies to each fixed
control. Record responder EV, reply root and unilateral gain. No favorable subset
or new opponent selected from results is permitted.

A self-profile comparison changes both players. The fixed-target comparison
keeps the opponent unchanged, so a responder EV change has a clear interpretation
for that opponent. Neither comparison isolates a pure variance effect: fixed
node work also changes update counts/time weights. Both average books share one
learning trajectory. Three seeds do not establish population confidence bounds.
