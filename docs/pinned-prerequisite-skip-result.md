fully validated prerequisite graph could serve six later consumers in each
archive root while an independent guard checked pinned bytes, source, aliases
and graph integrity. The one fixed ordinary→guarded-skip complete pair ran

## Result

**The pair failed the unchanged exact scientific-and-work identity gate.**
Both children completed within the original 900-second cap, and the pair
completed within 1,800 seconds. The ordinary child made 14 original
prerequisite loads across two roots. The guarded child made two original
loads and 12 explicit guarded returns. The 432 profiles, 1,152 fixed
conditions, three native workers, complete saved results and context match.
The four work counters below do not.

The predeclared gate required those counters to match, so identical poker
values alone cannot admit this candidate. The pair runner recorded

the fixed pair was not retried.

| Observed duration | Ordinary | Guarded skip |

No reference output entered training; no new training or default admission

## Reproduction and boundaries

The [data-only verifier](../scripts/report_guarded_skip_failure.py) checks
every listed source, own and raw member hash, their Git publication order,
the pinned runtime/license and original caps, all complete child scopes,
the ordinary predecessor identity and the exact four-field difference.
Poker, numerical and reference imports are blocked while it renders the
[machine-readable summary](../results/guarded-prerequisite-skip/report/summary.json).
Python 3.11.17 and 3.12.15 produce byte-identical JSON, SHA-256
`aa81c862946096a299f2673669f9848ea0b4d4239a088f2acd02b8d446d42f81`.
The report source and tamper tests are qualified separately from the earlier
source and pair commits; local and hosted final results are recorded below
when complete.

From a normal clone with the committed lockfile, run:

```sh
uv run --locked python scripts/report_guarded_skip_failure.py
python3 results/guarded-prerequisite-skip/pair-raw/verify.py.txt
```

The compressed raw archive has 31 members and verifies 17,357,388 original
bytes, including the preflight, both complete child records and failure log.
Its three public files match GitHub blob hashes and sizes. The first local
qualification logs were lost from temporary storage in a Mac restart;
all four roles were rerun against the unchanged source, and only the
second complete cohort is in the public source archive.
